# PillowPillow Homebrew Tap

Casks and formulae for PillowPillow tools. Each file in `Casks/` and `Formula/`
is written by the release workflow of its project — do not edit generated files
by hand.

## Casks

```bash
brew install --cask PillowPillow/tap/den
brew install --cask PillowPillow/tap/teashot
brew install --cask PillowPillow/tap/wikai
```

## Formulae

```bash
brew install PillowPillow/tap/envctl
```
